# Goals

I want to create a simple frappe application that helps me manage my livestock and track how much I'm spending on them, what my mortalities are, how much profit I'm making etc. Because this is a big and ambitious project, we're going to do it in phases and I'd like to make it more intricate as time goes by.

Since this is a large field, I'm starting off initially with a smaller scope on one type of animal (broilers) but all the systems we create should work for any other types of animals cattle, pigs, goats, fish, etc.
